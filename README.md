# 1 + 2 = 3

Математическая веб-игра для смартфонов. Без зависимостей и сборки.

Публичный адрес: https://duman-sadu.github.io/bir-eki-ush/

Публикация через GitHub Pages из корня ветки `main`. Для обновления сайта отправьте изменения в эту ветку. Файл `.nojekyll` отключает обработку Jekyll.

## Запуск

Нужен Node.js версии 20 или выше.

```sh
npm start
```

Откройте http://localhost:3213. Для игры с телефона подключите его к той же Wi-Fi сети и откройте `http://<локальный-IP-компьютера>:3213`. При необходимости разрешите Node.js доступ в частной сети в брандмауэре Windows.

## Правила

- Ответ всегда 1, 2 или 3. На компьютере работают и клавиши 1–3.
- В самих примерах используются только числа 1, 2 и 3 со знаками плюс и минус.
- После каждых трёх правильных ответов в пример добавляется одно число: четвёртый пример содержит три числа, седьмой — четыре.
- Верхнего ограничения уровня нет. Время на пример: `8000 / (1 + (уровень − 1) × 0.12)` миллисекунд. На первом уровне — 8 секунд, на пятом — примерно 5,4, на десятом — 3,85. С каждым уровнем время уменьшается.
- Очки за правильный ответ: `round(100 × уровень² × (1 + 0.5 × доля_оставшегося_времени))`. На первом уровне — 100–150, на пятом — 2500–3750, на десятом — 10000–15000. Быстрый ответ даёт больший бонус.
- Одна попытка: первая ошибка или истечение времени сразу завершает игру. Ответ на границе времени уже не засчитывается. Можно начать новую попытку кнопкой «Ещё раз».
- Отсчёт начинается при показе примера. Переходы между примерами не учитываются. Время в фоновой вкладке учитывается.
- Рекорд сохраняется в этом браузере, если доступно локальное хранилище. Для режима с таймером используется отдельный рекорд, поскольку старая система очков несопоставима с новой.

Это браузерный прототип, не установочный пакет Android/iOS. Шрифт загружается из Google Fonts; при отсутствии сети используется системный шрифт.

## Қазақша интерфейс және нәтижемен бөлісу

Ойын интерфейсі толық қазақша. Ойын басталғанға дейін немесе аяқталған соң атыңызды енгізуге болады. Атыңыз осы браузерде сақталады. Бос қалса, «Ойыншы» деп көрсетіледі.

Ойын аяқталғанда «WhatsApp арқылы бөлісу» батырмасы атыңыз, ұпайыңыз, деңгейіңіз және дұрыс жауап саны бар хабарламаны ашады. Алушыны таңдап, хабарламаны өзіңіз жібересіз. Жіберілетін мәтін экранда алдын ала көрсетіледі және оны қолмен көшіруге болады.

Қолданылған сілтеме пішімі: [WhatsApp ресми анықтамасы](https://faq.whatsapp.com/5913398998672934).

Хабарламаға ойынның жалпыға қолжетімді сілтемесі қосылады: https://duman-sadu.github.io/bir-eki-ush/. Жергілікті нұсқадан бөліскенде де осы сілтеме қолданылады. Негізгі мекенжай `index.html` ішіндегі canonical сілтемесінде сақталған. Бұл достар арасында нәтижемен бөлісу мүмкіндігі; ортақ онлайн рейтинг әзірге жоқ.

## Проверка

```sh
npm test
```

Проверяются рост сложности без ограничения уровня, корректность 4500 примеров, ограничение чисел до 1–3, убывание времени, награды и отклонение просроченных ответов.
