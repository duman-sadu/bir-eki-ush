# 1 + 2 = 3

Математическая веб-игра для смартфонов с установкой на главный экран и офлайн-режимом. Для самой игры не нужны библиотеки или сборка; Playwright используется только для проверок и подготовки значков.

Публичный адрес: https://duman-sadu.github.io/bir-eki-ush/

Публикация через GitHub Pages из корня ветки `main`. Перед каждым обновлением игры увеличьте версию `CACHE` в `sw.js` и обновите список `SHELL` с актуальными версиями файлов. Затем отправьте изменения в эту ветку. Файл `.nojekyll` отключает обработку Jekyll.

## Запуск

Нужен Node.js версии 20 или выше.

```sh
npm start
```

Откройте http://localhost:3213. Для игры с телефона подключите его к той же Wi-Fi сети и откройте `http://<локальный-IP-компьютера>:3213`. При необходимости разрешите Node.js доступ в частной сети в брандмауэре Windows.

## Правила

- Ответ всегда 1, 2 или 3. На компьютере работают и клавиши 1–3.
- В самих примерах используются только числа 1, 2 и 3 со знаками плюс и минус.
- После каждых трёх правильных ответов в пример добавляется одно число: четвёртый пример содержит три числа, седьмой — четыре.
- Верхнего ограничения уровня нет. Время на пример: `8000 / (1 + (уровень − 1) × 0.12)` миллисекунд. На первом уровне — 8 секунд, на пятом — примерно 5,4, на десятом — 3,85. С каждым уровнем время уменьшается.
- Очки за правильный ответ: `round(100 × уровень² × (1 + 0.5 × доля_оставшегося_времени))`. На первом уровне — 100–150, на пятом — 2500–3750, на десятом — 10000–15000. Быстрый ответ даёт больший бонус.
- Одна попытка: первая ошибка или истечение времени сразу завершает игру. Ответ на границе времени уже не засчитывается. Можно начать новую попытку кнопкой «Ещё раз».
- Отсчёт начинается при показе примера. Переходы между примерами не учитываются. Время в фоновой вкладке учитывается.
- Рекорд сохраняется в этом браузере, если доступно локальное хранилище. Для режима с таймером используется отдельный рекорд, поскольку старая система очков несопоставима с новой.

## Установка и игра без интернета

Откройте публичный сайт онлайн и дождитесь надписи «Ойын сақталды». Файлы игры сохранятся на устройстве. После этого можно закрыть страницу и открывать игру без сети. Используются системные шрифты, поэтому для интерфейса не нужны внешние загрузки.

- Android: кнопка «Телефонға орнату», если её предлагает браузер, либо меню Chrome → «Установить приложение» / «Добавить на главный экран».
- iPhone: Safari → «Поделиться» → «На экран “Домой”» → «Добавить»; оставить включённым открытие как веб-приложение, если этот переключатель показан. [Инструкция Apple](https://support.apple.com/en-lamr/guide/iphone/iphea86e5236/ios).
- После установки игра открывается отдельным окном с собственным значком. Это устанавливаемая веб-версия, без публикации в магазинах.
- WhatsApp требует интернет. Имя и рекорд сохраняются локально; удаление данных сайта может удалить и офлайн-файлы, и рекорд. Браузер и установленная версия на некоторых устройствах могут иметь разные хранилища.
- Новая версия скачивается при открытии онлайн. Кнопка «Ойынды жаңарту» применяет её вне активной партии. Автоматической перезагрузки во время игры нет.
- Аналитика офлайн-партий не доставляется: очередь последующей отправки пока не реализована. Локальный рекорд от сети не зависит.

Для service worker нужен HTTPS или localhost. Обычный HTTP-адрес компьютера в Wi-Fi подходит для просмотра игры, но не для проверки установки и офлайн-режима.

## Қазақша интерфейс және нәтижемен бөлісу

Ойын алдында «3, 2, 1» кері санағы көрсетіледі. Есептің уақыты тек содан кейін басталады. Ойын кезінде тақырып пен ережелер жасырылып, ықшам ойын экраны ашылады.

WhatsApp сілтемесінде ойыншының аты мен ұпайы сақталады. Досы сілтемені ашқанда сол нәтиже және одан озу үшін қанша ұпай керектігі көрсетіледі. Өз нәтижесімен бөліскенде жаңа шақыру жасалады. Бұл достық жарыс: сілтемедегі ұпай серверде тексерілмейді, ойыншыларға есептер кездейсоқ беріледі.

Ойын интерфейсі толық қазақша. Ойын басталғанға дейін немесе аяқталған соң атыңызды енгізуге болады. Атыңыз осы браузерде сақталады. Бос қалса, «Ойыншы» деп көрсетіледі.

Ойын аяқталғанда «WhatsApp арқылы бөлісу» батырмасы атыңыз, ұпайыңыз, деңгейіңіз және дұрыс жауап саны бар хабарламаны ашады. Алушыны таңдап, хабарламаны өзіңіз жібересіз. Жіберілетін мәтін экранда алдын ала көрсетіледі және оны қолмен көшіруге болады.

Қолданылған сілтеме пішімі: [WhatsApp ресми анықтамасы](https://faq.whatsapp.com/5913398998672934).

Хабарламаға ойынның жалпыға қолжетімді сілтемесі қосылады: https://duman-sadu.github.io/bir-eki-ush/. Жергілікті нұсқадан бөліскенде де осы сілтеме қолданылады. Негізгі мекенжай `index.html` ішіндегі canonical сілтемесінде сақталған. Бұл достар арасында нәтижемен бөлісу мүмкіндігі; ортақ онлайн рейтинг әзірге жоқ.

## Аналитика

Включён сбор посещений, начала/завершения партий, результатов и нажатий WhatsApp без имён игроков в проект PostHog EU владельца. Отдельный кабинет с отчётами ещё не создан: для этого нужно подключение аккаунта с правами управления. Схема показателей и состояние подключения: [docs/analytics.md](docs/analytics.md).

## Проверка

```sh
npm test
```

Проверяются рост сложности без ограничения уровня, корректность 4500 примеров, ограничение чисел до 1–3, убывание времени, награды и отклонение просроченных ответов.

Браузерная проверка PWA (нужен установленный Edge/Chrome/Chromium, при необходимости задайте `BROWSER_EXECUTABLE`):

```sh
npm ci
npm run test:pwa
```

Проверяет сайт в подпапке, значки, обработку кнопки установки, офлайн-перезагрузку и партию, сохранение рекорда, ссылки-вызовы и обновление без прерывания партии. Реальный системный диалог установки Android/iOS нужно проверять на устройстве. `npm run icons` пересоздаёт PNG из `icons/icon.svg`.

Механика обновления следует [жизненному циклу service worker](https://web.dev/learn/pwa/update).
